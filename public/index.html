BiliMerge

此 Worker 在每次请求时拉取 Biliverse ADBlock 与 Global 的 latest 发布物，构建成一个 Surge 模块与两份合并脚本。

安装合并模块：bilimerge.sgmodule

安装前务必卸载原始 ADBlock 和 Global 模块。同时安装会导致同一 URL 被重复处理。

工作方式

  • 仅在 Worker 构建期合并；不代理 Bilibili 请求。
  • 模块按 URL 分诊：仅命中一块时只执行该块；重叠时按 ADBlock → Global 串联。
  • Surge 对每个请求只执行一次合并脚本，且只收到一次 $done()。
  • 上游暂不可用时，脚本端 fail-open：原请求/响应不被拦截。模块更新端则返回错误，保留旧模块配置。

调试路径

  • merged-request.js
  • merged-response.js

上游版本随 latest 自动更新；不需要手工改版本号。
